# Grocery Management System

## Project Description
The Grocery Management System is a simple project designed to manage grocery products, prices, quantities, and shopping details.

## Features
- Add grocery items.
- View available grocery items.
- Update product prices and quantities.
- Search for grocery products.
- Calculate the total cost of grocery items.

## Technologies Used
- Visual Studio Code (VS Code)
- Python
- Text files for data storage

## How to Run
1. Open the project folder in VS Code.
2. Open the Python source code file.
3. Run the program using the Run button or terminal.

## Applications
- Grocery shops
- Small supermarkets
- Local retail stores

## Conclusion
This project helps users manage grocery products and calculate prices easily. It is useful for understanding basic programming and inventory management.
